# 旅行計画立て直しAIアプリ

旅行中に予定が崩れたとき、AIが状況に応じてプランを立て直してくれるWebアプリです。

---

## 解決したい課題

既存アプリは旅行前の計画には優れている一方、旅行中の急な予定変更には十分対応できないことが課題だと感じました。

このアプリは、台湾旅行で実際に予定が崩れ、立て直しに苦労した経験をきっかけに、「旅行中のリカバリー」に特化して開発しました。

## 仕組み：3つのAIエージェント

1つの質問に対して、役割の異なる3つのAIエージェントが連携して回答を作ります。

| エージェント  | 役割                     |
| ------- | ---------------------- |
| Agent A | 理想的なプランを作成             |
| Agent B | 予算・時間・移動などの制約を現実的にチェック |
| Agent C | AとBの内容をまとめ、最終的な提案として提示 |

天気・交通状況・施設情報などの外部データを事前に取得し、3エージェントの判断材料として渡すことで、状況に応じた現実的な提案を行います。

## 主な機能

* チャット形式でのプラン相談・再提案
* ユーザー認証・プランの保存／削除
* プランのURL共有
* 他ユーザーのプランを閲覧・コピーできる公開ライブラリ
* 現在地の自動取得による出発地入力
* 利用状況の分析ダッシュボード（管理者用）

## 使用技術

* **言語**：Python
* **フレームワーク**：Streamlit
* **AI**：OpenAI GPT-4o（3エージェント構成）
* **認証・DB**：Supabase
* **外部API**：OpenWeather API（天気）／Serper API（交通・画像）／Google Maps API（施設・ルート）
* **デプロイ**：Streamlit Community Cloud
* **リポジトリ管理**：GitHub
* **開発支援**：生成AIを活用し、実装方法の検討やエラー原因の整理を行いながら開発

## 成果

* 初期検証：3名を対象に検証・改善し、利用者満足度 53% → 81%
* 利用者検証：20名以上を対象に2回の検証・改善を行い、利用者満足度 78% → 89%
* 実旅行検証：その後2名に実際の旅行で利用してもらい、実環境での課題を特定し、改善機能を実装
